Chromium (Chrome, Edge, Brave) — geliştirici moduyla kurulum

  1. GitHub releases sayfasından son sürüm .zip dosyasını indir ve bir klasöre çıkart.
  2. Tarayıcının adres çubuğuna şunu yazıp Enter'a bas: chrome://extensions
  3. Sağ üst köşedeki Geliştirici modu (Developer mode) anahtarını aç.
  4. Sol üstteki Paketlenmemiş öğe yükle (Load unpacked) butonuna tıkla.
  5. Çıkarttığın kick-takipci-chromium klasörünü seç.
